# Privacy and local data

The current interface does not require a FretFlow account. Scores and preferences are stored in local browser storage. The core player loads bundled assets. Tuner audio is processed locally by the pitch detector; the current source contains no upload path for that microphone audio.

The current app does not expose the legacy AI interface; its unused code was removed from this publication copy. No guarantee is made about browser extensions, operating-system services, dependency-installation traffic, or future contributions.

Microphone access is optional and only needed for tuning. Keep original scores and export copies you need: local browser data can be cleared, quota failures are not surfaced reliably, and the uploaded library is capped at 30 entries. Different browsers and the desktop app may use separate profiles.
